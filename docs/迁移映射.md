<a id="compatibility-scope"></a>
## 兼容范围

当前仓库的兼容行为如下：

1. `bot-task-platform-v1-design.md` 和 `bot-task-platform-v1-flowcharts.md` 是历史文件级入口标识；当前仓库不再包含这两个文件，现有导航统一从 [文档目录.md](文档目录.md) 进入。
2. [文档目录.md](文档目录.md) 保留 `#core-model`、`#platform-overview`、`#architecture-overview`、`#rest-conventions`、`#error-registry`、`#security-baseline`、`#mvp-scope`、`#conclusion`、`#migration-map` 和 `#alignment-issues` 等显式兼容锚点。
3. 本文件中的 `index.md#...` 和 `results-and-artifacts.md#...` 是旧链接的语义标识。仓库当前不包含对应旧文件；若发布环境要求旧 URL 自动跳转，必须由站点路由或重定向配置另行保证。
4. 迁移映射不代表旧章节内容与新文档逐字等价；当前契约只以“当前权威链接”为准。
