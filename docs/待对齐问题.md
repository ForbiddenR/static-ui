<a id="issue-registration-rules"></a>
## 问题记录规则

1. 新问题使用下一个未占用的 `ALIGN-NNN`，不得因排序、合并或关闭而重编号。
2. “受影响的当前权威”必须链接到现行契约；登记表不得以摘要改写这些契约。
3. “当前契约或差异”只陈述已存在的事实；“待决策内容”只列需要裁决的边界，不预设结论。
4. 决策完成后先补充可追溯的决策或变更链接，再将状态更新为 `已决策待落地` 或 `已关闭`。
5. 一个问题影响多个主题时仍保留一个主 ID；主题文档通过该 ID 回链，避免建立重复问题记录。
6. 未完成决策前，各主题继续遵循自身当前权威，不从流程图、示例、MVP 范围或表结构反向推导新语义。
